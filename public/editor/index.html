    Good to know

    The secret link is set in Cloudflare as the variable EDIT_TOKEN. To change the link, change that value there and deploy again.

    If you forget a password you changed here, open Cloudflare > Storage & Databases > KV > your namespace, delete the entry named cfg:auth, and the original EDIT_PASSWORD works again.
